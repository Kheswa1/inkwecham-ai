# INKWENATIVE AI Continuity — InkweCham AI Repository

This repository is part of the historical INKWENATIVE AI / InkweCham AI development lineage. The current main branch README describes the earlier ChamAI e-commerce assistant and storefront concept. Other visible branches preserve additional work, including a KHESH execution-boundary rebuild, workspace/voice work and video-generator source.

## Preserve before consolidation
- `main`: earlier ChamAI / e-commerce concept and nested video-generator source.
- `feature/inkwecham-ai-workspace-voice`: workspace and voice-related application work.
- `rebuild/issue-13-khesh-boundary`: KHESH execution-boundary rebuild; its README describes authenticated SYSTEM execution, fail-closed adapter configuration and execution audit expectations.
- `video-generator-v1`: historical video-generator branch.
- `video-generator/`: nested Next.js video studio source.

Do not assume these branches are merged, deployable, or mutually redundant. Inspect commit ancestry, diffs, application files, Supabase migrations and deployment history before any consolidation.

## Current architectural direction
Preserve the original InkweCham/INKWENATIVE AI identity and evolve the system toward the unified INKWE AI architecture. KHESH is the user-facing coordinator. The product must not become a second independent AI brain alongside the central INKWE intelligence. E-commerce, workspace, voice and creative capabilities can remain specialist workflows with their own data and authorization boundaries.

## Verification gaps
The repository README on main is only a short concept description. The KHESH rebuild branch documents remaining gates including real authorized SYSTEM provider connection, complete authentication UI, automated boundary/persistence tests and end-to-end Supabase verification. Treat these as branch-documented gaps until independently rechecked.
